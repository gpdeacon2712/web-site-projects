Responsive Styling Techniques Used

For this version of the webpage, I extended the original styling so that the content adapts more effectively to desktop, tablet and mobile screen sizes.

  • Added the viewport meta tag so mobile browsers use the physical width of the device.
  • Used a responsive container with a maximum width to prevent text lines becoming too long on larger screens.
  • Used relative sizing and the CSS clamp() function so headings adapt to different screen widths.
  • Made the Oxford United image responsive using width: 100% and height: auto.
  • Added a media query for screens below 600 pixels to reduce margins, padding and heading spacing.
  • Used the CSS box-sizing property to make element widths easier to manage.
  • Centred the main content on larger screens while allowing it to use most of the available width on mobile devices.
  • Replaced inline styles with reusable CSS classes to make the code more consistent and easier to maintain.
  • Added visible keyboard focus styling to improve navigation for users who do not use a mouse.
  • Used line spacing and scalable text to maintain readability on small and large screens.

Responsive Design Reflection

The original page remained functional on a mobile device, but it was designed mainly for a desktop-sized screen. Fixed image sizes, page margins and padding could make the content appear cramped or require unnecessary scaling on smaller devices.

The revised page uses responsive CSS so that the same HTML content can be presented appropriately across mobile, tablet and desktop screens. The image reduces in size when required, the text remains readable, and the content container adjusts to the available width without causing horizontal scrolling.

I tested the page using the responsive device tools in the browser developer tools at mobile, tablet and desktop widths. This showed that responsive web design involves more than making a desktop page smaller. It also requires suitable spacing, readable text, flexible images and controls that remain easy to use on touchscreen devices.
