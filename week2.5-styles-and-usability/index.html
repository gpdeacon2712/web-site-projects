Styling and Accessibility Techniques Used

To improve the appearance and accessibility of this webpage, I applied several HTML and CSS techniques.

  • Declared the page language as British English.
  • Added semantic header, main, section and footer landmarks.
  • Added a skip link for keyboard and screen-reader users.
  • Used meaningful headings in a logical order.
  • Provided descriptive alternative text for the image.
  • Made the image responsive on smaller screens.
  • Used visible keyboard-focus indicators.
  • Used readable text spacing and line height.
  • Selected foreground and background colours with strong contrast.
  • Expanded professional abbreviations for clarity.
  • Identified that the LinkedIn link opens in a new tab.
  • Kept presentation in CSS rather than using inline styles.

These enhancements improved the readability, navigation and presentation of the page while helping me understand the difference between content structure, visual design and accessible interaction.
