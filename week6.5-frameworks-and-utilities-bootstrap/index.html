  1. JavaScript sends a request using fetch().
  2. The response is converted from JSON.
  3. The image address is read from the message property.
  4. The page displays the returned image.
  5. An alert reports loading, success or failure.

Bootstrap and original application comparison

1

Speed of development

Bootstrap reduced the amount of custom CSS needed for the grid, navigation, cards, form controls, buttons, spacing and feedback messages.

Some initial time was still required to learn the framework’s class names and component structure.

2

Responsiveness

Bootstrap’s mobile-first grid allowed the same content to stack on narrow screens and form multiple columns at wider breakpoints.

The original application provided more detailed control, but required manually written media queries and layout rules.

3

Usability

Bootstrap supplied familiar and consistently styled navigation, cards, controls, validation feedback, buttons and alerts.

Accessibility still required semantic HTML, accurate labels, keyboard support, meaningful alternative text and live status messages.

Overall evaluation

Bootstrap accelerated development and produced a consistent responsive interface. The original application offered greater styling freedom and avoided a framework dependency, but required more custom CSS and manual testing.
