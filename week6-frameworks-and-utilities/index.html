    Responsive Styling Techniques Used

    I extended the original styling so that the content adapts more effectively to desktop, tablet and mobile screen sizes.

    • Added the viewport meta tag so mobile browsers use the physical width of the device.
    • Used a responsive container with a maximum width to prevent text lines becoming too long.
    • Used relative sizing and the CSS clamp() function for responsive headings.
    • Made images responsive using width: 100% and height: auto.
    • Added a media query for screens below 600 pixels.
    • Added visible keyboard focus indicators.
    • Used mobile-friendly buttons with a minimum height of 44 pixels.

    Responsive Design Reflection

    The original page remained functional on mobile devices, but it was designed mainly for a desktop-sized screen. Fixed image sizes, larger margins and wider layouts could make the content appear cramped on smaller displays.

    The revised page uses responsive CSS so that the same HTML content can be presented appropriately across mobile, tablet and desktop screens. Images reduce in size when required, text remains readable and the content adjusts without introducing horizontal scrolling.

    HTML DOM Methods Added

    The page uses JavaScript DOM methods to select, create, update, insert and remove elements while the webpage is running.

    • getElementById() selects individual elements using their unique IDs.
    • querySelector() selects the chosen contact-method radio button.
    • querySelectorAll() retrieves all selected interest checkboxes.
    • createElement() creates the submission summary heading, paragraph, list items and button.
    • appendChild() inserts newly created elements into the summary.
    • replaceChildren() clears previously generated summary content.
    • classList.add(), classList.remove() and classList.toggle() change the appearance and visibility of elements.
    • setAttribute() adds an accessible label to the dynamically created removal button.
    • textContent safely changes displayed text.
    • insertAdjacentElement() inserts a DOM status message beneath the main heading.

    These methods allow the webpage to react dynamically without requiring the browser to load a new page.
